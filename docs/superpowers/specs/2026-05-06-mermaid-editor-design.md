## 1. 背景与目标

### 1.1 背景

需要在本地或浏览器中快速编写 Mermaid 语法、实时查看渲染结果，并通过多种预览主题切换，便于在不同展示风格下检查图表可读性与美观度。

### 1.2 产品目标

- **编辑**：提供面向 Mermaid 源码的编辑能力，支持常见图类型（flowchart、sequence、class、state、ER、gantt 等，以 Mermaid 官方支持为准）。
- **预览**：与编辑区联动，在合理延迟内展示渲染后的矢量/ DOM 图。
- **主题**：预览区支持**至少多种**预设视觉主题；用户通过**点击**即可切换当前预览所用主题，无需改源码。

### 1.3 成功标准（验收导向）

- 用户修改源码后，预览在可接受时间内更新且无破坏性报错提示。
- 用户可在界面上**一键/一点**切换主题，切换后全图样式一致应用新主题。
- 在主流桌面浏览器中可用；核心路径无阻塞性缺陷。

## 4. 功能需求

### 4.1 编辑器（FR-ED）

| ID | 描述 | 优先级 |
|----|------|--------|
| FR-ED-01 | 提供多行文本编辑区，用于输入与修改 Mermaid 源码 | P0 |
| FR-ED-02 | 支持常见编辑操作：输入、删除、撤销/重做（若平台原生支持可依赖浏览器/组件） | P1 |
| FR-ED-03 | 语法错误时，在预览区或独立区域展示可读错误信息（文案或 Mermaid 返回信息） | P0 |
| FR-ED-04 | （可选）从空白模板或示例图一键载入，降低上手成本 | P2 |

### 4.2 预览（FR-PV）

| ID | 描述 | 优先级 |
|----|------|--------|
| FR-PV-01 | 根据当前编辑器内容渲染 Mermaid 图；内容与编辑器**一致** | P0 |
| FR-PV-02 | 编辑停止或防抖后更新预览，避免每次按键都全量重绘导致卡顿 | P0 |
| FR-PV-03 | 渲染失败时不清空上次成功结果，或明确区分「错误态」与「上次成功」 | P1 |
| FR-PV-04 | 大图时预览区可滚动或缩放（至少一种），避免内容溢出不可见 | P1 |

### 4.3 主题切换（FR-TH）

| ID | 描述 | 优先级 |
|----|------|--------|
| FR-TH-01 | 内置**不少于 3 种**预览主题（例如：默认浅色、深色、高对比或品牌中性色等，具体命名与色板在实现阶段确定） | P0 |
| FR-TH-02 | 用户通过**点击**界面控件（如主题 chips、下拉、或主题列表）切换主题 | P0 |
| FR-TH-03 | 切换主题**不修改** Mermaid 源码；仅改变预览层样式变量或 Mermaid 支持的 `theme`/`themeVariables` 等配置 | P0 |
| FR-TH-04 | 当前选中主题在 UI 上有明确选中态 | P1 |
| FR-TH-05 | （可选）记住用户上次选择的主题（`localStorage` 或等价机制） | P2 |

### 4.4 其他（FR-MISC）

| ID | 描述 | 优先级 |
|----|------|--------|
| FR-MS-01 | （可选）导出预览为 SVG/PNG | P2 |
| FR-MS-02 | （可选）从 URL 或文件导入 `.mmd` / 文本 | P2 |

## 5. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 常规图（例如少于 500 行）防抖后渲染交互流畅；避免无防抖的逐键全量解析 |
| 兼容性 | 明确目标：最新两个版本的 Chrome / Edge / Firefox / Safari 桌面端（实现阶段可收窄并写入 README） |
| 可访问性 | 主题切换控件可被键盘聚焦与操作（P1） |
| 安全 | 若未来支持从 URL 拉取内容，需考虑 XSS/开放重定向等风险（本阶段可标为后续） |
| 国际化 | 首版 UI 文案可为中文或中英混合；错误信息可保留英文原文便于检索（P2） |

## 6. 方案备选与推荐

以下为交付形态与技术栈的备选，**不改变**上文功能需求边界，仅影响实现路径。

| 方案 | 说明 | 优点 | 缺点 |
|------|------|------|------|
| A. Web SPA（推荐） | 单页应用 + `mermaid` npm 包在浏览器渲染 | 部署简单、主题用 CSS 变量或 Mermaid `initialize` 统一切换、易分享 | 需构建工具链 |
| B. 桌面壳（Electron/Tauri） | 内嵌 WebView 与 A 类似 | 离线体验好、可挂系统菜单 | 体积与发布成本高 |
| C. VS Code / Cursor 扩展 | 在编辑器侧预览 | 与写文档工作流一体 | 分发与审核流程更重 |

**推荐**：方案 **A（Web SPA）**，在空仓库中从零用 Vite + React/Vue 或纯 TS 均可；主题通过 Mermaid 初始化配置 + 预览容器 CSS 变量组合实现点击切换。

## 7. 架构与设计概要（初版）

- **单页布局**：左侧或上方为编辑器，右侧或下方为预览；主题切换为顶栏或预览区上方的**可点击主题控件**。
- **数据流**：编辑器文本 → 防抖 → `mermaid.parse` / `render` → 注入预览 DOM；主题 ID 变更 → 重新 `initialize` 或更新主题变量 → 对同一源码重新渲染。
- **主题模型**：`ThemeId` 枚举 + 每主题一份 `{ mermaidTheme, cssVariables }` 映射表；切换时更新状态并触发重绘。
- **错误处理**：try/catch 包裹渲染；展示 `error.message` 或友好映射文案。

*详细接口与文件结构在通过本需求评审后，由 `writing-plans` 产出实现计划。*

## 8. 验收检查清单（初版）

- [ ] 输入合法 Mermaid，预览与源码一致。

- [ ] 切换主题后无需改源码即可看到样式变化。
- [ ] 当前主题在 UI 上可辨识。
